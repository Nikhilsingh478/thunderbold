ANIMATION SYSTEM — IMPLEMENT ALL OF THESE:

Use Framer Motion for all animations.
Import: import { motion, useInView, 
useAnimation } from 'framer-motion'

Standard entrance animation variants 
to define once and reuse:

const fadeUp = {
  hidden: { opacity: 0, y: 40 },
  visible: { 
    opacity: 1, 
    y: 0,
    transition: { duration: 0.6, ease: [0.22, 1, 0.36, 1] }
  }
}

const fadeIn = {
  hidden: { opacity: 0 },
  visible: { 
    opacity: 1,
    transition: { duration: 0.8 }
  }
}

const slideLeft = {
  hidden: { opacity: 0, x: -40 },
  visible: { 
    opacity: 1, 
    x: 0,
    transition: { duration: 0.6, ease: [0.22, 1, 0.36, 1] }
  }
}

const stagger = {
  visible: {
    transition: { staggerChildren: 0.15 }
  }
}

Use useInView hook with once: true so 
animations only trigger once when entering 
viewport, not every time:

const ref = useRef(null)
const isInView = useInView(ref, { 
  once: true, 
  margin: "-100px" 
})

Wrap each section in a motion.div with 
ref and animate based on isInView.
