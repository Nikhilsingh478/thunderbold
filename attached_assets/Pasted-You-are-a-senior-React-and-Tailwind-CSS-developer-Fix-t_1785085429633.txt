horizontal overflow:

1. Any fixed width on cart item container or 
   card that exceeds mobile viewport width
   Example: w-[500px] or min-w-[400px]

2. Any flex row where children don't have 
   proper constraints:
   - Product image with fixed width pushing 
     content outside container
   - Product name not truncating or wrapping
   - Price and controls in a row without 
     flex-shrink or min-w-0

3. Any padding or margin on the page root 
   container that pushes content right

4. Any grid with fixed column widths that 
   exceed mobile width

5. Order Summary section — "Calculated" text

STEP 3 — FIX THE CART ITEM CARD:

The cart item card has three sections in a row:
- Product image (left)
- Product details — name, size, price (middle)  
- Quantity controls — minus, number, plus (right)

This flex row is causing the overflow.
Fix it like this:

<div className="flex items-center gap-3 w-full 
  min-w-0 overflow-hidden">
  
  {/* Image — fixed size, flex-shrink-0 */}
  <div className="flex-shrink-0 w-20 h-20 
    md:w-24 md:h-24">
    <img className="w-full h-full object-cover" />
  </div>
  
  {/* Details — must have min-w-0 to allow shrinking */}
  <div className="flex-1 min-w-0">
    <p className="truncate font-medium">
      {item.name}
    </p>
    <p className="text-sm">Size: {item.size}</p>
    <p className="text-sm">₹{item.price}</p>
  </div>
  
  {/* Quantity controls — flex-shrink-0 to stay visible */}
  <div className="flex-shrink-0 flex items-center 
    gap-2">
    <button>-</button>
    <span>{item.quantity}</span>
    <button>+</button>
  </div>
  
</div>

THE CRITICAL FIX HERE IS:
- Image div must have flex-shrink-0 so it 
  does not grow
- Middle details div must have flex-1 AND 
  min-w-0 — without min-w-0 flex children 
  do not shrink below their content size 
  which causes overflow
- Product name must have truncate class 
  so long names do not push layout
- Quantity controls must have flex-shrink-0 
  so they stay fully visible
